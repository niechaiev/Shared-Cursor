The concept of alive cursors for player lobby. 
<br>Each player's cursor is in world space so that virtual hands create an illusion of touching the environment.
<br>Players can select emotes from emote wheel.
<br>The position, rotation and animations are replicated between players.

<br>This rough demo shows Photon Fusion's networking between two Unity editors:
